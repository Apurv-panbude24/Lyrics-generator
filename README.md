# Lyrics Generator

An AI-powered lyrics generator built with Python 3.9 that uses NLP techniques to generate song lyrics based on a given prompt or style.

## Demo

A demo video is included in the repository: `lyrics generator.mp4`

## Features

- Generate song lyrics using natural language processing
- Customizable style and tone inputs
- Lightweight Python script — no complex setup required

## Getting Started

### Prerequisites

```bash
pip install -r requirements.txt
```

### Run

```bash
python code.py
```

## Tech Stack

- Python 3.9
- OpenAI API
- NLP text generation
